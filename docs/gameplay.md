# Gameplay guide

## The game

Jigsaw Friends Online is a cooperative puzzle room. One to eight players work on the same 8-by-6 puzzle board. A room can be open for other players to discover, or locked for a private group or solo play.

## Starting a room

The room creator becomes its host and chooses a room name and starter picture. An open room appears in the room browser; a locked room stays out of the browser and blocks new players. Players can also join an open room directly with its six-character code.

The host can start a puzzle with just one player. Players who join after a puzzle has started can help, but only players present at the start earn a star for that puzzle.

## Solving a puzzle

- Each puzzle contains 48 pieces arranged as eight columns by six rows.
- The board does not show a placement grid. Use the reference-picture button when you need to check the image.
- Drag any loose piece onto the board. Correct placements lock into place; incorrect placements remain movable.
- All pieces are shared, so every player can contribute to the same puzzle.

## Stars and completion

When the last piece is placed, the puzzle is complete. Each player who was in the room when that puzzle began earns one star. The room displays each player’s running total. Since this is cooperative, players can finish together with the same score.

The completion screen lets players vote to replay the current puzzle or start the next one. When votes are tied, the host’s vote decides. The next puzzle can also start automatically after the short countdown.

## Puzzle lineup and picture suggestions

The lineup holds the room’s upcoming pictures. The host can upload a JPG or PNG directly and add it to the lineup without approval. Other players can submit a JPG or PNG upload or a direct image link. Their suggestions wait for the host to approve them into the lineup or disapprove them.

The host can select a queued picture as the active puzzle. If the lineup is empty when the room advances, the game chooses one of its temporary sample puzzles.
